# Предпросмотр сайта ПРОСВЕТ

Эта ветка содержит готовую статическую версию для GitHub Pages.

Исходный код: ветка `codex/premium-homepage-stage-1`, коммит `5757ae1`.
Сборка Next.js выполнена с `output: export`, `basePath: /glazing-premium-website` и локальными изображениями без серверной оптимизации. Префикс изображений добавлен только в изолированную копию исходников для этой сборки. `.nojekyll` сохраняет доступ к каталогу `_next`.

Для включения: Settings → Pages → Source: Deploy from a branch → Branch: codex/site-preview → /(root) → Save.

После успешной публикации адрес: https://vladmeserakov6-png.github.io/glazing-premium-website/

Это снимок первой итерации. Изменения исходной ветки автоматически сюда не переносятся. Серверных заявок нет; задание формируется локально в браузере. Изображения — AI-визуализации, не портфолио компании. Бренд временный. Индексация отключена.
