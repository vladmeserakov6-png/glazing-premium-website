# ПРОСВЕТ — архитектура остекления

Первый этап премиального сайта по остеклению: адаптивная главная, дизайн-система и клиентские сценарии. «ПРОСВЕТ» — рабочее название концепции, а не подтвержденное название компании.

Добавлена интерактивная итерация: пошаговый подбор, избранное, сравнение, галерея, схема конструкции, черновик и копирование задания, мобильные действия. Проверка функций и воспроизводимый экспорт для GitHub Pages описаны в [руководстве](docs/INTERACTIVE_UPGRADE.md).

## Запуск

Требуется Node.js 24 LTS (`.nvmrc`) и npm. Секреты, БД и внешние сервисы для первого этапа не нужны.

```bash
cd /workspace/glazing-premium-website
npm ci
npm run dev
```

Откройте адрес из вывода Next.js. По умолчанию — порт 3000. Другой порт: `npm run dev -- --port 3001`. На другом компьютере используйте путь своего checkout. Кеш npm задан в `.npmrc` как `/tmp/glazing-npm-cache` для работы в облачной среде с недоступным для записи домашним каталогом.

Production:

```bash
npm run build
npm run start
```

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

E2E использует production-сборку. Playwright поднимает `npm run start`, если порт 3000 свободен. Остановите dev-сервер на этом порту перед проверкой. В облаке используется `/usr/bin/chromium`. Если системного Chromium нет, выполните `npx playwright install chromium`. Альтернативный путь задается через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Проверяются desktop и mobile: каталог, фильтры, диалоги, фокус, FAQ, меню, валидация, содержимое скачанного задания, отсутствие отправки данных, reflow 320–1440 CSS px, изображения, robots.txt и axe WCAG AA. Автоматический аудит не заменяет проверку скринридером. CI: `.github/workflows/ci.yml`.

## Возможности

- Русскоязычная главная: Header, Hero, преимущества, каталог, подход, вдохновение, FAQ, CTA, Footer.
- Восемь услуг с фильтрами и описаниями в диалоге.
- Мобильное меню, клавиатурная навигация, reduced motion, семантическая разметка.
- Форма задания: выбор объекта и решения, необязательные размеры и комментарий, React Hook Form + Zod, скачивание UTF-8-файла. Персональные данные не запрашиваются. Задание не отправляется на сервер и не сохраняется в БД.
- Локальные WebP через Next/Image и локальный Manrope с кириллицей. Внешние фотосервисы и Google Fonts не нужны.
- Metadata API, favicon и русская 404. До согласования реальных данных и домена концепция закрыта от индексации через metadata и robots.txt.

## Границы этапа

Это концепция для проверки, а не опубликованный коммерческий сайт. Карточки открывают подробности в диалоге; отдельные SEO-страницы услуг относятся к следующему этапу. Цены, телефон, реквизиты, отзывы, гарантии и показатели компании не выдумываются. Форма не имитирует отправку заявки. Калькулятор, CRM, серверные формы, юридические страницы, аналитика и production SEO — следующие этапы.

Перед публичным выпуском нужны утвержденный бренд, реальные контакты, услуги, домен, права на контент, юридические тексты и проверенный канал доставки заявок. После этого можно снять `noindex`, добавить canonical, sitemap и бизнес-разметку. Подробнее: [план](PROJECT_PLAN.md), [дизайн-система](docs/DESIGN_SYSTEM.md), [ассеты](docs/ASSETS.md), [ревью](docs/REVIEW.md).

Для просмотра первой итерации через браузер подготовлена отдельная ветка `codex/site-preview`. Пошаговое включение размещения: [GitHub Pages](docs/GITHUB_PAGES.md).
