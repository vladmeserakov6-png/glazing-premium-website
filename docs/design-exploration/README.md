# Десять работающих концепций главной

Это отдельная дизайн-итерация по запросу заказчика. Улучшение основного коммерческого сайта приостановлено до выбора направления. Исходная главная, ее компоненты и содержимое корня опубликованного предпросмотра сохраняются.

## Как смотреть

Галерея после обновления GitHub Pages: https://vladmeserakov6-png.github.io/glazing-premium-website/concepts/index.html

Нажмите «Открыть страницу» либо «Посмотреть целиком». В каждой концепции сверху есть ссылка «Все 10 вариантов», стрелки перехода и кнопка ♡. Избранное хранится локально в браузере; выбор не отправляется в Codex автоматически. Для дальнейшей работы сообщите номера понравившихся страниц в чате.

Пока размещение GitHub Pages ожидает завершения, все десять направлений можно увидеть на [общем снимке галереи](overview.webp). Это изображение для визуального сравнения; работающие страницы открываются через галерею после завершения размещения.

## Работающие элементы

- Мобильное меню, якорная навигация, переключение между концепциями.
- Фильтрация каталога, раскрытие всех восьми услуг, подробности выбранного решения.
- Нативный dialog: Escape, блокировка фонового взаимодействия, удержание и возврат фокуса.
- Подбор направления по объекту и приоритету; перенос выбора в задание.
- Проверка размеров, скачивание текстового задания без передачи данных на сервер.
- FAQ и локальное избранное в общей галерее.

Финансовый калькулятор и настоящая доставка заявки не имитируются. Тарифы, контакты, отзывы, гарантии и сведения о компании не выдуманы. ПРОСВЕТ — рабочее название. Изображения — архитектурные AI-референсы.

## Устройство

Это автономные HTML/CSS/JS-страницы для сравнения дизайна. Next.js отдает их из `public/concepts/`; тот же каталог можно разместить статически на GitHub Pages. Они не подключают глобальную шапку и подвал основного сайта.

- `design-lab/concepts.mjs` — десять направлений, тексты и порядок разделов.
- `design-lab/render.mjs` — десять отдельных первых экранов и общий семантический каркас.
- `design-lab/concepts.css` — базовые элементы, десять визуальных систем и адаптивные композиции.
- `design-lab/interaction.js` — поведение меню, каталога, подбора и форм.
- `design-lab/gallery.css`, `gallery.js` — общая галерея и избранное.
- `scripts/build-concepts.mjs` — генерация статических HTML и копирование ресурсов.
- `public/concepts/` — готовые страницы и включенные в репозиторий ресурсы.
- `tests/e2e/concepts.spec.ts` — браузерные проверки всех вариантов.

Для пересборки на Node.js 24: `npm run concepts:build`. Затем запускайте проект обычным способом. Локальный адрес галереи — путь `/concepts/index.html` на сервере Next.js. Скрипт не изменяет файлы основной главной страницы.

Для повторного получения превью запущенных страниц: `npm run concepts:screenshots`. Скрипт использует Playwright и Sharp; сервер должен быть запущен. Другой адрес задается переменной `CONCEPTS_BASE_URL`, включая путь `/concepts/`. Перед снимком скрипт ожидает загрузку шрифтов и декодирование изображений, чтобы превью не показывало пустые фотографии.

Для публикации копируется только каталог `public/concepts/` в `concepts/` ветки `codex/site-preview`. Корневой `index.html`, существующие ресурсы и настройки Pages не заменяются. Обновление выполняется обычным push с сохранением истории ветки.

## Ресурсы

Четыре изображения взяты из предыдущей итерации. Еще пять созданы специально для этой серии: `night.webp`, `quiet.webp`, `urban.webp`, `forest.webp`, `warm.webp`. Все включены локально в `assets/media/` и не требуют фотосервиса. Manrope и Cormorant Garamond распространяются по SIL OFL; лицензии находятся в `assets/fonts/`.

Превью галереи сняты с реальных работающих страниц. Полные снимки desktop и mobile сохранены в `docs/design-exploration/previews/`.

Результаты проверки: [VALIDATION.md](VALIDATION.md). Все 60 браузерных тестов, TypeScript, lint и production build прошли. Исходники этой итерации — ветка `codex/ten-homepage-concepts`; готовая галерея — каталог `concepts/` в `codex/site-preview`.
