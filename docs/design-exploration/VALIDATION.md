# Проверки десяти концепций

Проверено в текущей облачной среде на Node.js 24.19.0, Next.js 16.4.2, Chromium / Playwright. Результаты относятся к завершенной дизайн-итерации, а не к полной готовности коммерческого сайта.

| Проверка | Результат |
| --- | --- |
| `npm run concepts:build` | Сгенерированы все 10 страниц и галерея; повторный запуск сохраняет результат |
| `npm run concepts:screenshots` | Сняты 10 превью галереи и 20 полных desktop/mobile-снимков |
| `npm run lint` | Успешно, без ошибок и предупреждений |
| `npm run typecheck` | Успешно |
| `npm run build` | Production-сборка прошла |
| `npm run test:e2e` | 60/60, 0 пропусков, 0 нестабильных результатов |
| Каталог и сценарии всех концепций | 20 успешных тестов: по 10 desktop и mobile |
| Ресурсы, reflow, axe всех концепций | 20 успешных тестов: по 10 desktop и mobile |
| Галерея и избранное | 2 успешных теста: desktop и mobile |
| Исходная главная | Все существующие 18 тестов прошли |

В каждом варианте проверены: навигация, четыре начальные и восемь раскрытых услуг, фильтры, описание услуги, перенос выбора в форму, проверка размеров, содержимое скачанного файла, отсутствие POST-запросов, подбор решения по приоритету, FAQ с клавиатуры, удержание и возврат фокуса, мобильное меню и сохранение избранного.

Для всех страниц проверена ширина 320, 390, 768, 1024 и 1440 CSS px. Автоматический axe-аудит с тегами WCAG 2 A/AA, 2.1 AA и 2.2 AA не выявил нарушений на страницах и в диалогах. Это не является полной сертификацией доступности и не заменяет ручную проверку скринридером.

Дополнительно проверен статический экспорт под префиксом `/glazing-premium-website/`: все 10 страниц, изображения, шрифты, открытие диалогов, возврат к галерее и ссылка на исходную главную. Ошибок JavaScript и неуспешных запросов ресурсов не обнаружено.
