# TAHION — «Больше света. Ближе к миру»

Реализация выбранного пользователем макета от 23 октября 2026 года. Источник — `codex/tahion-light`.

## Композиция

Верх главной повторяет выбранный порядок: шапка и морской первый экран → технический блок → услуги. Далее сохранены преимущества, подбор решения, подход, галерея, FAQ и подготовка задания.

Светлая палитра, тонкая типографика, слово TAHION вместо прежнего рабочего названия, круглые контурные кнопки, голубое стекло и архитектурные фотографии объединены в `src/app/tahion.css`. Логотип, favicon, метаданные, подвал и экспортируемое задание используют новый бренд.

Фон первого экрана и пять дополнительных визуализаций подготовлены отдельно от макета. На сайте используются настоящие HTML-заголовки, ссылки и кнопки, а не изображение интерфейса. Исходные WebP находятся в `public/images/tahion-*.webp`. Изображения — архитектурные и технические иллюстрации, не портфолио и не чертеж конкретной оконной системы.

В техническом блоке три интерактивные детали: стеклопакет, профиль, примыкание. Кнопка «Изучить конструкцию» раскрывает пояснения; «Посмотреть по слоям» переключает визуализацию на разнесенную схему. Режим reduced motion поддерживается. Каталог, фильтры, избранное, сравнение, пошаговый подбор, галерея и локальный черновик сохранены.

## Сборка и размещение

```bash
npm ci
npm run lint
npm run typecheck
npm run build
npx playwright test tests/e2e/home.spec.ts tests/e2e/interactions.spec.ts
npm run preview:export
npm run preview:check
```

Статическая сборка теперь по умолчанию рассчитана на основной путь `/glazing-premium-website`. Все локальные WebP автоматически получают адаптивные версии при экспорте. Публичный адрес:

https://vladmeserakov6-png.github.io/glazing-premium-website/

Для сохранения прежней ссылки `/upgrade/` можно собрать ту же версию с `NEXT_PUBLIC_BASE_PATH=/glazing-premium-website/upgrade` и соответствующим `NEXT_PUBLIC_SITE_URL`; для проверки используйте тот же префикс. Статический экспорт размещается в ветке `codex/site-preview`. История Git сохраняет предыдущую версию. Десять ранее опубликованных концепций не перерабатываются.

## Проверка

TypeScript, ESLint без предупреждений, production build. 34 браузерных сценария desktop/mobile включают порядок первых трех блоков, новый бренд, навигацию, reflow 320–1440 px, каталог, подбор, избранное, сравнение, галерею, форму, скачивание задания, ограниченные хранилища и axe WCAG AA. Отдельно проверяется статический экспорт: 15 изображений раскрытой главной и основные сценарии на двух размерах экрана. Артефакты — `/tmp/tahion-review/`.

Формы по-прежнему готовят задание локально. Получатель и сервис реальных обращений не подключены. Индексация остается отключенной до завершения коммерческого выпуска. Предыдущие сведения об интерактивных функциях и зависимостях сохранены в `INTERACTIVE_UPGRADE.md`.
