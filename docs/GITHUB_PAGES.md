# Как открыть сайт через GitHub Pages

## Интерактивная итерация

Исходники улучшенной версии находятся в `codex/interactive-upgrade`. Для проверки предусмотрен отдельный адрес:

https://vladmeserakov6-png.github.io/glazing-premium-website/upgrade/

Сборка воспроизводится командой `npm run preview:export`, проверяется `npm run preview:check`. Содержимое `out/` размещается в папке `upgrade/` ветки `codex/site-preview`; корневая главная и десять ранее опубликованных концепций сохраняются. Адрес доступен после успешной публикации GitHub Pages. Подробности: [интерактивная версия](INTERACTIVE_UPGRADE.md).

## Исходный предпросмотр

Подготовлены две ветки:

- `codex/premium-homepage-stage-1` — исходный Next.js-проект для разработки и ревью.
- `codex/site-preview` — отдельный готовый статический снимок главной для предпросмотра.

`main` не изменена. Ветка предпросмотра не требует слияния исходного кода в основную ветку.

## Одноразовое включение в браузере

1. Войдите в свой аккаунт GitHub и откройте [настройки Pages репозитория](https://github.com/vladmeserakov6-png/glazing-premium-website/settings/pages).
2. В разделе **Build and deployment** найдите **Source** и выберите **Deploy from a branch**.
3. В поле **Branch** вместо **None** выберите **codex/site-preview**.
4. В поле папки оставьте **/(root)**.
5. Нажмите **Save**.
6. Дождитесь публикации. После ее завершения на этой странице появится **Visit site**.

Ожидаемый адрес после включения и успешного завершения публикации:

https://vladmeserakov6-png.github.io/glazing-premium-website/

Этот адрес не считается работающим, пока GitHub Pages не включен и размещение не завершено. Кнопка публикации облачной среды в Codex сохраняет среду разработки и не включает GitHub Pages.

Если меню Branch еще не показывает новую ветку, обновите страницу. Если настройки Pages недоступны, необходим аккаунт с правами администратора репозитория. Не вводите токены или пароли в чат.

## Ограничения предпросмотра

Это статический снимок первой итерации: меню, каталог, диалоги и скачивание задания работают в браузере. Серверной доставки заявок нет. Рабочее название — ПРОСВЕТ, изображения — архитектурные AI-референсы. Индексация отключена.

Изменения ветки исходников автоматически не обновляют ветку предпросмотра. Следующая версия потребует новой статической сборки и обновления `codex/site-preview`.

## Сведения для разработчика

Снимок собран из коммита `5757ae1` в отдельной временной папке с `output: "export"`, `basePath: "/glazing-premium-website"`, локальными изображениями и `images.unoptimized: true`. Пути `src` изображений в этой копии дополнены тем же basePath согласно документации Next/Image. Файл robots в копии помечен `force-static`. Обычная конфигурация Next.js в исходной ветке не менялась.

Для проверки готовый экспорт запускался статическим HTTP-сервером под адресным префиксом репозитория. Проверены загрузка изображений, шрифтов и favicon, фильтры, диалоги, скачивание задания и мобильное меню. В опубликованной ветке находится `.nojekyll`, необходимый для каталога `_next`.

Инструкция по настройкам сверена с [официальной документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
