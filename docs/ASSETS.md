# Изображения и шрифты

Все четыре изображения созданы OpenAI Image Generation специально для этой концепции. Это архитектурные визуализации, а не реальные работы компании. Они не подтверждают техническую реализуемость или характеристики конкретной системы.

| Файл в `public/images/` | Содержание |
| --- | --- |
| `architecture.webp` | Современный дом с панорамным фасадом |
| `interior.webp` | Светлая гостиная с панорамными окнами |
| `terrace.webp` | Остекленная терраса с видом на сад |
| `balcony.webp` | Светлый балкон с белыми оконными рамами |

Исходные генерации сохранены в `/workspace/generated_images` текущей среды. Для приложения изображения преобразованы в WebP без увеличения разрешения. Весь нужный контент включен в репозиторий: внешние URL и каталог генераций приложению не нужны. Адаптивная загрузка — Next/Image, размеры зарезервированы контейнерами.

Перед коммерческой публикацией заказчик должен утвердить визуализации либо предоставить фотографии с правами. Для портфолио нужны фотографии подтвержденных объектов.

Шрифт Manrope — SIL Open Font License 1.1, локальный пакет `@fontsource-variable/manrope` с кириллицей и лицензией внутри пакета. Иконки Lucide React — ISC. Запросов к Google Fonts нет.
