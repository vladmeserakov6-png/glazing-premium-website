# Дизайн-система

TAHION: «Больше света. Ближе к миру». Светлая архитектура, тонкая кириллическая типографика, морской первый экран, технический блок с голубым стеклом и фотографии услуг.

Основы компонентов — `src/app/globals.css` и `interactions.css`. Финальные токены и визуальные правила выбранной темы — `src/app/tahion.css`, подключенный последним. Подробности реализации: [TAHION](TAHION.md).

## Компоненты

- `Button` / `ButtonLink`: primary, light, outline, dark; кнопка для действия, ссылка для перехода.
- `SectionHeading`: номер, надзаголовок, заголовок и пояснение.
- `Reveal`: CSS и IntersectionObserver, reduced motion; содержимое видно без анимации и JavaScript.
- `Modal`: нативный dialog, доступное имя, удержание фокуса, Escape, возврат фокуса, блокировка фонового взаимодействия.
- `ProjectProvider`: единый сценарий «описание услуги → задание».

## Адаптивность

Диапазоны: 480, 768, 1024, 1200, 1600 px. Каталог: четыре колонки на широком экране, две на планшете и телефоне. Мобильное меню до 1024 px. Диалог прокручивается внутри экрана. Основные кнопки высотой 43–54 px. Декоративные мелкие подписи не несут обязательной информации.

## Контент

Все интерфейсные тексты на русском. Визуализации обозначаются как референсы. Отсутствующие сведения о компании не заменяются выдуманными. CTA готовит файл задания. Контент услуг отделен от компонентов и готов к расширению на отдельные страницы.
